# codex-box 1.2.20

适配 Codex 26.928.20755，修复浅深色模式下输入框外围及 dot 页面的背景遮挡，让壁纸连续显示，并将会话标签、来源摘要和已编辑文件卡片调整为贴合主题的高透明度表面。

- 移除新版输入框外围的实色底和顶部渐变，保留输入框自身表面及消息滚动占位。
- dot 聊天主区透出主题壁纸；右侧资料窗口采用单层轻薄玻璃表面。
- 会话选中标签、来源摘要、已编辑文件卡片支持浅深色模式，移除文件行的实色填充。
- 来源与 dot 资料窗口的吸顶标题、顶部补色伪元素同步透明，保留吸顶、滚动、按钮反馈与权限控件状态。
- macOS 与 Windows 同步更新主题注入规则。

## 下载

- macOS：`codex-box-1.2.20-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。

## 验证

双平台生产 CSS 回归与新版 Codex 实际样式表验证覆盖输入框装饰层、dot 聊天与资料窗口、卡片背景、标题伪元素、浅深色切换及控件交互；macOS 已完成本机效果验收。Windows 发布工作流包含前端与 Rust 测试、换肤及进程隔离、官方客户端验证，以及安装包构建和启动检查。
