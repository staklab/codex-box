# codex-box 1.2.18

同步修复 macOS 与 Windows 在新版 Codex 中的主题壁纸显示，让聊天区、项目列表和设置主区连续透出壁纸。

- 适配新版窗口、页面背景层与工作区背景伪元素，解决浅色模式发白、深色模式发黑、壁纸被遮挡的问题。
- 移除项目列表独立叠加的 65% 背景，保留会话选中态、悬停与控件交互。
- 修复设置页仅左侧显示壁纸的问题，保留设置卡片和菜单底色。
- Windows 同步支持旧 class 与新版 data-theme 明暗标记，并补齐输入框外围装饰渐变修复。

## 下载

- macOS：`codex-box-1.2.18-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：提供 EXE 与 MSI 安装包，通常选择 EXE 即可。

## 验证

双平台生产 CSS 回归覆盖明暗切换、页面与侧栏透明、设置主区、输入框外围、滚动占位及局部卡片保留。macOS 已完成本机安装验收。Windows 构建工作流执行前端与 Rust 测试、换肤与进程隔离测试、官方客户端空白登录环境测试及安装包构建和启动冒烟检查；官方客户端测试不覆盖已登录会话中的全部页面。
