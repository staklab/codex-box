# codex-box 1.2.24

修复新版 Codex 左侧两层侧栏遮挡主题壁纸的问题，并修复 macOS 本地 token 统计在会话续跑、计数器重置及归档场景中的漏算与重复计数。

- macOS 与 Windows 同步移除侧栏容器新增的底色，使浅色、深色模式下的壁纸显示与主区域一致，保留行悬停、选中状态及拖动布局。
- macOS 合并同一会话的多个续跑日志段，同时去重当前与归档副本；记录页显示最早开始时间、最新模型及活动时间。
- macOS 正确识别原生会话累计计数器重置，继续统计后续请求，并跳过重复回放的用量样本。
- macOS 升级后保留缓存中的首屏记录，在后台重新解析旧日志缓存、修复历史用量账本并更新汇总。
- 更正 macOS 设置中的统计说明：总 token 为输入加输出，缓存输入已包含在输入中。

## 下载

- macOS：`codex-box-1.2.24-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。

## 验证

macOS 已通过 90 项费用统计、会话归属、记录快照及设置回归测试，并用真实日志核对历史用量补回及汇总与账本一致性；本机安装效果已由用户确认。双平台主题背景生产样式回归通过。Windows 发布工作流执行前端与 Rust 测试、换肤及进程隔离、官方客户端验证、安装包构建和启动检查。
