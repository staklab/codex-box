# codex-box 1.2.12

本版本补齐 macOS 通用架构安装包，并增强聚合网关下的账号无感切换与会话连续性。

## 主要更新

- 恢复应用或网关重启前最近使用的会话账号绑定
- 正在运行的会话优先沿用原账号，不因本地配额快照提前迁移
- 原账号收到真实账号级失败后，自动切换至可用账号并继续转发同一请求
- 切换时保留 thread 标识、请求正文与 `previous_response_id`，确保上下文连续
- 成功切换后持久化新的会话账号归属，后续请求继续使用新账号
- 新会话继续按账号健康度和剩余额度进行聚合选路

## 验证

- macOS 全量自动化测试通过
- 聚合网关账号选路、失败重试、会话粘性及持久化恢复回归测试通过
- Release 通用架构构建验证通过，同时支持 Apple Silicon 与 Intel Mac
- DMG 内应用版本、Bundle ID、架构、签名和 Applications 链接均已核对

由于发布时有账号正在处理请求，本次未执行真实账号切换，以避免中断现有会话；账号切换行为由隔离的网关集成测试覆盖。

## 安装

下载 `codex-box-1.2.12-macOS.dmg`，打开后将 `codex-box.app` 拖入 Applications。

当前安装包采用 ad-hoc 签名且未做 Apple 公证。首次启动若被 Gatekeeper 阻止，请在“系统设置 → 隐私与安全性”中确认允许打开。
