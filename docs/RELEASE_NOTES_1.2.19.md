# codex-box 1.2.19

修复“使用情况与计费”和“键盘快捷键”设置页顶部的实色矩形及渐变遮挡，让工具栏和快捷键搜索框透出主题壁纸。

- macOS 与 Windows 同步移除设置页吸顶工具栏的背景和底部渐变，兼容浅色、深色模式。
- 快捷键搜索框填充改为透明，保留控件边界、搜索输入、吸顶行为和标签选中态。
- 保留设置卡片及工具栏范围外的背景样式。

## 下载

- macOS：`codex-box-1.2.19-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。

## 验证

双平台生产 CSS 回归和新版 Codex 实际样式表验证覆盖工具栏背景、渐变、明暗切换、搜索输入、吸顶与卡片保留；macOS 已完成本机效果验收。Windows 发布工作流包含前端与 Rust 测试、换肤及进程隔离、官方客户端空白登录环境验证，以及安装包构建和启动检查。
