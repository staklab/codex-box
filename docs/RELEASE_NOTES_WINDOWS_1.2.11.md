# codex-box Windows v1.2.11

本版本聚焦 Windows 客户端的界面、账号聚合与主题稳定性。

## 主要变化

- 使用窗口内确认层替代系统原生二级弹窗，避免弹窗超出软件边界。
- 重做 Windows 界面视觉，导航精简为账号、桌面、主题和记录四个入口。
- 多账号聚合改为直接通过 OpenAI OAuth 登录新账号，无需填写接口地址或 API Key。
- 主题市场支持一次点击完成下载、安装、重启连接和应用，操作完成前保持明确的忙碌状态。
- 修复 Codex Desktop 强制退出尚未完成时提前重启导致的换肤延迟与无响应。
- 主窗口默认尺寸调整为 460 × 720，并改进小窗口内的布局和滚动体验。

## 安装包

- NSIS 安装程序：`.exe`
- Windows Installer：`.msi`

本版本仅修改 Windows 客户端，不包含 macOS 应用代码变更。
