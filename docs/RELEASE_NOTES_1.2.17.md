# codex-box 1.2.17

修复主题壁纸模式下，输入框外围在浅色模式显示白色、深色模式显示黑色背景的问题。

- 移除对话底部装饰渐变的实色背景，让输入框外围透出主题壁纸。
- 保留输入框本身的玻璃底色、末条消息的滚动占位，以及内容卡片背景。
- 兼容新旧明暗模式标记，延续 1.2.16 的新版 Codex 壁纸兼容修复。

验证：新旧外观标记、深浅模式、输入框外围透明、滚动占位、内容卡片隔离、重复换肤与恢复的回归检查通过；隔离浏览器计算样式读回通过；macOS Release 构建与签名校验通过。
