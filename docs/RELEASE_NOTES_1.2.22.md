# codex-box 1.2.22

修复 Codex 26.928.31416 中 dot 页面顶部遮挡主题壁纸的渐变条，让浅色和深色模式下的顶部区域保持透明。

- 识别挂在窗口外壳上的 dot 顶部装饰层，移除浅色模式的白色渐变和深色模式的黑色渐变。
- 保留顶部头像、通话按钮、原有布局及其他预览工具栏的渐变。
- macOS 与 Windows 同步更新主题注入规则。

## 下载

- macOS：`codex-box-1.2.22-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。

## 验证

双平台生产 CSS 回归覆盖顶部装饰层透明、尺寸和变换保留、其他预览工具栏渐变及按钮交互。新版 Codex 实际样式表的隔离验证覆盖六组浅深色切换与顶部按钮点击；macOS 已完成本机效果验收。Windows 发布工作流包含前端与 Rust 测试、换肤及进程隔离、官方客户端验证，以及安装包构建和启动检查。
