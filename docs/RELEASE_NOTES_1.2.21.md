# codex-box 1.2.21

修复 Codex 26.928.20755 中 dot 输入框下方的实色横条，以及 `tibo` 固定标签的背景遮挡，让两处表面透出主题壁纸。

- dot 普通输入区与回复输入区的底边改为透明，保留原有 12px 底部间距。
- 固定标签的选中层采用随浅深色模式变化的高透明度玻璃底，保留标签边界和按钮交互。
- macOS 与 Windows 同步更新主题注入规则。

## 下载

- macOS：`codex-box-1.2.21-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。

## 验证

双平台生产 CSS 回归覆盖固定标签、输入区底边、底部间距和控件交互。新版 Codex 实际样式表的隔离验证覆盖浅深色切换、输入区尺寸及标签按钮；macOS 已完成本机效果验收。Windows 发布工作流包含前端与 Rust 测试、换肤及进程隔离、官方客户端验证，以及安装包构建和启动检查。
