# codex-box 1.2.25

修复新版 Codex dot 页面顶部在浅色模式下出现白边、深色模式下出现黑边并遮挡主题壁纸的问题。

- macOS 与 Windows 同步兼容 Codex 26.1007 的浮动标题渐变层，同时继续支持旧版顶部结构。
- 顶部装饰层透出主题壁纸，保留头像、通话按钮、定位和原有高度。
- 按 dot 独有的定位锚点限定修复范围，其他预览工具栏的渐变保持原有显示。

## 下载

- macOS：`codex-box-1.2.25-macOS.dmg`，Apple Silicon / Intel 通用安装包。
- Windows x64：EXE、中文 MSI 和英文 MSI，通常选择 EXE 即可。
